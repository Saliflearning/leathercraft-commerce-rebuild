# ADR 0001: Use a clean-room reconstruction

- Status: Accepted
- Date: 2026-08-31

## Context

Recovered versions contain valuable learning evidence but also team-authorship ambiguity, private course and business data, insecure implementation patterns, incomplete provenance, and rights-unclear assets.

## Decision

Create a new repository with newly authored code, prose, fictional product records, and original vector compositions. Use the historical material only to establish bounded facts and lessons. Do not copy source, data, screenshots, names, feedback, or media from the old packages.

## Consequences

The result can be reviewed and licensed coherently, and recruiters can distinguish past learning from current ability. It is not a historical source archive or a claim that the old application has been modernized line by line.
