# Security policy

## Supported scope

This repository is a static educational demonstration. The current default branch is the only supported version. There is no server, authentication, payment, order processing, upload, or customer-data surface.

## Reporting

Please report a suspected vulnerability through GitHub's private vulnerability-reporting feature when available. Do not include real credentials, payment data, or personal information in a public issue.

Useful reports explain the affected commit, reproducible steps, likely impact, and a minimal proof of concept. Dependency alerts and reports about bypassing the local-state or publication scanners are in scope.

## Important boundary

The browser-local cart is untrusted demonstration state. It is validated for stable interface behavior, not presented as an authorization, pricing, inventory, or transaction control.
